## Native routes, headers and result semantics

The selected Teams session supplies authority and audience; these are Teams Admin operations, not Graph lookups. Compiled PolicyRP carries MPACmdlet/command/correlation headers without generated forest discovery. Modern ConfigAPI performs bound service discovery, validates origin/forest target and omits MPACmdlet. The selected modern helpers pass null ApiVersion/SchemaVersion and omit those queries; Broadcast exposure is a separate explicit query. Modern configuration identities are one opaque escaped component; compiled scoped identities split the first slash. The companion audit owns pinned-source provenance; the tables below also link current SDK behavior.

| Operation | Native contract | Result/safety boundary |
|---|---|---|
| Read/list/filter | GET `/Skype.Policy/configurations/{type}[/configuration/{identity}]` | Object or bare collection, local wildcard selection. Compiled exact Global versus modern case-insensitive Global ordering stays distinct. No invented pagination. |
| Compiled create/update/delete | POST collection; PATCH/DELETE selected identity | Known bound DTO fields; compiled string Force and selector-bearing DELETE. Set preparation GET and PATCH preserve separate receipts. |
| Modern create/update/delete | POST collection; PUT/DELETE selected identity | Optional typed values; omitted versus bound identity/default distinct, modern delete bodyless. Explicit POST/Get convenience can fail after creation. |
| Broadcast exposed read | GET with `ExposeSDNConfigurationJsonBlob=true` | Sensitive SDN getter surface differs from ordinary read; exposing a token is not a license to print or persist it. |
| User/tenant/group grants | PATCH `/Skype.Policy/users/{user}/policies/{type}`; PATCH `/Skype.Policy/tenants/policies/{type}`; POST `/Skype.Policy/groupPolicyAssignments/{group}/policyTypes/{type}` | Compiled DTO casing/additionalParameters/rank differs from modern helper coercion and truthy-rank omission. Group 202/204 are receipts, not effective-policy convergence or implicit polling. |

Writes never replay automatically or roll back unrelated stages. Accepted malformed responses retain HTTP metadata with decode errors; successful discovery is not mutation acceptance. Read/modify/write list operations have no implicit ETag or atomicity guarantee. Generic authorization failure does not establish a flight restriction. Exact server rules, future cloud behavior and effective client policies remain separate from local typed decoding.
