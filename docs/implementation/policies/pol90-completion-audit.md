## Finite boundaries, rather than unlimited permutations

The optional “additional variants” previously listed in the integration report are improvement opportunities, not automatically missing product behavior. Normal operations have reachable typed response/receipt evidence, and the two parameterless default Grant Identity sets have source-defined invalid-invocation evidence instead of a fabricated HTTP success. This audit found no remaining command represented solely by its old blank 400/403 request table. Existing user InputObject success was already exercised by `TestUnitUserReadsUseAcceptanceResponses`; it must not be reported as an unimplemented positive merely because the older route-specific denial test is easier to find.

Source remains independently necessary. A modern branch's passing test does not settle an evidenced public conditional remoting branch. Conversely, generated AutoRest commands must not inherit a remoting blocker simply because they are PowerShell functions: pinned `CmdletConfig.json` identifies 15 of the 20 public functions here as `AutoRest`; only TenantFederation Get/Set and the three Edge builders are `Remoting` mappings. Eight OCE commands are conditionally loaded; the existing netcore conditional metadata/source audit, not failure of ordinary root import, defines their scope. 32 remaining commands resolve as compiled cmdlets.

Existing app-mode package refusal is not a tenant success.
- Tenant federation response-side domain choice/discriminator normalization is not a proved reversible request projection. Raw response data remains available; no guessed conversion or legacy fallback is added.
- Branding New remains empty-create only in current published documentation. Local image/slate/theme/reaction construction and a nested Set do not prove uploads, fetches, Premium rendering or assignment effects. Recording's published client-effect release caveat remains explicit.
